# Glossário e unidades

| Termo | Definição |
|---|---|
| B3 | Bolsa do Brasil |
| WIN | Código do contrato futuro mini de Ibovespa |
| IBOV | Índice Bovespa à vista, carteira teórica de ações/units |
| IND | Código do contrato futuro cheio de Ibovespa |
| Ponto | Unidade de cotação do índice |
| Tick | Variação mínima permitida de preço; confirmar especificação vigente |
| Trade/negócio | Execução realizada |
| Contrato | Unidade contratual negociada |
| Volume | Declarar sempre se é contratos, negócios ou financeiro |
| VWAP | Preço médio ponderado pelo volume |
| TWAP | Preço médio ponderado pelo tempo |
| CVD | Cumulative Volume Delta, delta acumulado |
| FVG | Fair Value Gap |
| ICT | Inner Circle Trader; conjunto de conceitos e terminologia de análise |
| VIX (Cboe) | Índice de volatilidade implícita de aproximadamente 30 dias do S&P 500, derivado de opções SPX |
| VXBR | S&P/B3 Ibovespa VIX; índice de volatilidade implícita de aproximadamente 30 dias associado ao Ibovespa |
| Volatilidade implícita | Volatilidade futura inferida dos preços de opções |
| Volatilidade realizada | Dispersão observada dos retornos históricos numa janela definida |
| Slippage | Diferença entre preço esperado e preço efetivo |
| Basis | Diferença entre preço futuro e referência à vista, com convenção definida |
| OOS | Out of sample, período fora da amostra de desenvolvimento |
| Point-in-time | Dado/vintage efetivamente disponível no instante histórico da decisão |

Usar unidades explicitamente: pontos, ticks, contratos, negócios, R$, R$/ponto, contratos/minuto, percentagem, volatilidade anualizada e hora com fuso. Não usar “volume” sem qualificação.

VIX Cboe e VXBR não são a mesma série, não têm o mesmo subjacente e não devem ser comparados como se os níveis fossem diretamente equivalentes.
