# Glossário e unidades

| Termo | Definição |
|---|---|
| B3 | Bolsa do Brasil |
| WIN | Código do contrato futuro mini de Ibovespa |
| IBOV | Índice Bovespa à vista |
| IND | Código do contrato futuro cheio de Ibovespa |
| Ponto | Unidade de cotação do índice |
| Tick | Variação mínima permitida de preço; confirmar especificação |
| Trade/negócio | Execução realizada |
| Contrato | Unidade contratual negociada |
| Volume | Declarar sempre se é contratos, negócios ou financeiro |
| VWAP | Preço médio ponderado pelo volume |
| TWAP | Preço médio ponderado pelo tempo |
| CVD | Cumulative Volume Delta, delta acumulado |
| FVG | Fair Value Gap |
| ICT | Inner Circle Trader; conjunto de conceitos e terminologia de análise |
| VIX | Índice de volatilidade implícita de opções do S&P 500 |
| Slippage | Diferença entre preço esperado e preço efetivo |
| Basis | Diferença entre preço futuro e referência à vista, com convenção definida |
| OOS | Out of sample, período fora da amostra de desenvolvimento |

Usar unidades explicitamente: pontos, ticks, contratos, negócios, R$, R$/ponto, contratos/minuto e hora com fuso. Não usar “volume” sem qualificação.
