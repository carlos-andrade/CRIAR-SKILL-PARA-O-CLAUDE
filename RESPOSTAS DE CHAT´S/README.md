# RESPOSTAS DE CHAT´S

Esta pasta é o destino obrigatório para arquivar as respostas produzidas nos chats relacionados com o projeto **CRIAR SKILL PARA O CLAUDE**.

## Regras de arquivo

1. Guardar cada resposta/conversa relevante nesta pasta, com ficheiro próprio.
2. Usar nomes descritivos, preferencialmente no formato `AAAA-MM-DD-assunto.md`.
3. Preservar o conteúdo técnico, decisões, requisitos, conclusões, alterações e pendências.
4. Não sobrescrever registos anteriores; acrescentar novos ficheiros.
5. Confirmar a gravação e a leitura do ficheiro no GitHub antes de declarar o arquivo concluído.
6. Quando o conteúdo for uma síntese e não uma transcrição integral, identificá-lo explicitamente.
